## What it does

Adds a smooth cursor-tracking glow/hover interaction to Webflow pages without rebuilding the entire site in custom code.

## How to use

1. Add the script to your Webflow project custom code (before `</body>`).
2. Drop the glow container element where your design expects it.
3. Publish and test on desktop — mobile falls back gracefully.

## Why I built it

I wanted the code-background aesthetic on blurrdstudio.com without sacrificing Webflow's editor workflow for marketing pages.
