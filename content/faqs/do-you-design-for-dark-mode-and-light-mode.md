Yes, when it makes sense for the product and audience. I design color tokens and contrast rules so both modes stay readable and consistent. I also test common components like tables, charts, and forms in both modes. If dark mode is optional, I still design the UI so it looks good in low-light contexts. Done right, modes feel intentional, not like an afterthought.
