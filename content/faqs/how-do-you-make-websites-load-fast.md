Speed comes from intentional design and clean implementation — not tricks. I optimize every layer of the build so pages load fast, feel responsive, and score well on Core Web Vitals.

## What I optimize

**Assets and media**
- Image compression, modern formats, and lazy loading where it helps
- Video and animation used sparingly — only when they add real value
- Font loading strategies that avoid layout shift and render blocking

**Code and architecture**
- Lightweight scripts — no bloated libraries for simple interactions
- Modern frameworks chosen for performance, not hype
- Efficient layouts with minimal DOM complexity and clean CSS

**Launch-ready performance**
- Core Web Vitals review before go-live: LCP, INP, and CLS
- Caching, CDN, and hosting configuration matched to your stack
- QA on real devices and network conditions — not just localhost

## Why this matters

Slow sites lose users, hurt SEO, and undermine trust — especially on mobile. Performance is a product decision, and I treat it as part of the build, not an afterthought.
