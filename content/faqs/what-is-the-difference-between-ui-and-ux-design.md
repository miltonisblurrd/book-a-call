UI and UX are related but not interchangeable. UX is the architecture — how the product is structured, how users move through it, and whether they can complete their goals. UI is the surface — the visual design, typography, color, and interaction details people see and touch.

## UX design (structure and flow)

- Information architecture: how content and features are organized
- User flows: the path from entry to task completion
- Wireframes and prototypes to test logic before visual polish
- Usability: reducing steps, clarifying labels, handling edge cases

## UI design (visuals and interactions)

- High-fidelity screens with typography, color, and spacing
- Component design: buttons, forms, cards, navigation patterns
- Interaction states: hover, active, loading, error, empty
- Visual consistency across screens and breakpoints

## Why both matter

Great UI on a broken flow still fails. A logical flow with ugly UI still loses trust. I design both together so the experience looks sharp and feels effortless — which is especially important for SaaS products where users judge credibility in seconds.
